# Privacy

The product privacy policy lives at [`docs/legal/privacy-policy.md`](docs/legal/privacy-policy.md).  
Hostable HTML mirror for Play Console: [`docs/store/privacy-policy.html`](docs/store/privacy-policy.html).

Key defaults for the Play v1 release (ADR-0024):

- Local-first; no account required for the opening campaign
- Analytics and crash reporting **off by default** (crash reporter is a local stub)
- Local export and deletion available in Settings
- Remote learner-code execution **not enabled** in this build
- Cloud sync UI not wired; API deletion exists for a future sync client
